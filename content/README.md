Systems of Agents is a series of experiments in how humans and agents can work together on increasingly complex tasks. The North Star is a personal agent that stays useful across sessions and keeps up as your world changes. The other test is whether a swarm can tackle a problem no single agent can solve reliably. We build in Pi, starting with long-lived sessions and shared workspaces, and publish the code and what we learn along the way.
